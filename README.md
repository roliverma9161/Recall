# Recall — Personal Digital Memory

Recall is a simple, responsive personal knowledge app designed to help people save and find things they want to remember.

## Current version

Phase 1 includes:
- React + Vite
- Tailwind CSS
- React Router
- Responsive sidebar and mobile menu
- Dashboard
- Memories
- Add Memory UI
- Search
- Collections
- Timeline
- AI Assistant placeholder
- Profile
- Settings
- Basic Express server

## Run the client

```bash
cd client
npm install
npm run dev
```

## Run the server

Open another terminal:

```bash
cd server
npm install
npm run dev
```

The frontend is intentionally simple and readable. Backend authentication, MongoDB, file uploads, OCR, embeddings and AI search will be added in later phases.
